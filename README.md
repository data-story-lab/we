# My Little Journey — GitHub Pages

A small, responsive scrapbook-style personal learning website.

## Files
- `index.html` — page content and navigation
- `style.css` — visual design and responsive layout
- `script.js` — hash-based page navigation

## Publish on GitHub Pages
1. Open your repository and upload these three files to the repository root.
2. Replace the existing `index.html`, `style.css`, and `script.js` if asked.
3. Commit the changes to your `main` branch.
4. In Settings → Pages, confirm the site publishes from `main` / root.
5. Wait for the Pages deployment to finish, then refresh the published site.

## Customising
- Replace the image URLs in `index.html` with images you have permission to use.
- Edit the text in the Week sections to add your own reflections.
- All navigation is handled by page hash links, so no server or build tools are required.
